# 🌤 Weather Dashboard

A modern Weather Dashboard built using HTML, CSS and JavaScript.

## 🚀 Features

- 🔍 Search weather by city
- 🌡 Current temperature
- ☁ Weather description
- 💧 Humidity
- 💨 Wind speed
- 🌍 Country information
- ⌨ Search using Enter key
- 📱 Responsive Design
- ✨ Modern Glassmorphism UI

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeatherMap API
